# Каркас для сайта info-it-skoof


## Как работает проект?
На сайте есть 3 разных вкладки с проектами. 2 из 3 (TYPER И MINIQUIZ) - это микросервисы.

<i>Микросервис</i> (с точки зрения фронтенд) - приложение, которое работает удаленно от основного приложения, но делится своими модулями.
Отображение (работа) виджетов или отдельных UI зависит от того какие модули мы разрешили для подключения к каркасу.

Для подключения я использовал 2 разных module-federation плагина. На каркасе используется webpack версия, на отдельных приложениях @originjs/vite-plugin-federation
